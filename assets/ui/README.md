# UI artwork

The files in this directory were created specifically for Make 5771 Great Again on 2026-09-08 using Google's Gemini image-generation tooling through Antigravity, from project-authored prompts.

They are original night-academy/observatory motifs and intentionally contain no 《忘却前夜》 characters, logos, screenshots, names, or extracted game artwork. They may be redistributed with this repository and its release binaries under the repository's MIT license.

Files:

- `night-observatory-banner.jpg` — run-page hero artwork
- `observatory-owl.jpg` — status and guidance illustration
- `archive-moth.jpg` — activity, waiting, and empty-state illustration

The generated source images were resized and JPEG-optimized for a small executable footprint. The pre-existing application icon and character emoji set are separate assets and were not replaced.
