## 下一步

1. 你从预览图里挑出要用的（按「分类 + 编号」告诉我就行）；
2. 我把选中的移到 `assets/art/<分类>/`，同时做素材**清单化重构**（键值索引、按需加载、显示尺寸降采样、缺失自动回退现有表情）；
3. 再加 `CREDITS.md` 逐图记录来源；
4. 需要更多角色（立绘原图、更多表情）时我继续按同样流程抓取——原图更大，只在你要的时候下。

> 抓取方式：Fandom 的 MediaWiki API（`list=allimages`）枚举文件，记录名称/尺寸/直链后下载原始文件，再用 Pillow 裁掉透明边并按用途降采样。没有解包游戏客户端，也没有绕过任何登录或付费内容。
