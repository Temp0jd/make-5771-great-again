## v0.4.9 · 流程交互修复与窗口比例落点

### 修复
- 步骤卡片点击即可选择；独立拖动手柄负责排序，不再覆盖卡片按钮和操作菜单。
- 简洁/专家模式切换独立成行，并标注各自显示的参数；增加模式显隐回归测试。
- 步骤文字自动换行、阶段标题换行，模板预览限制宽高，减少布局溢出。
- 保留原有角色装饰；补齐新标签使用的内嵌中文字形。

### 新增：识别成功后点击窗口比例位置
在点击落点设置中选择「点击窗口比例位置」，设置横向、纵向百分比。例如 25%、75% 表示目标游戏窗口客户区宽度的 25%、高度的 75%。

- 仍须图片识别成功，不会无条件点击。
- 支持普通识别步骤、分支触发点击、分支后续识别动作和视觉条件点击。
- 比例基于整个目标窗口客户区，而不是图片、搜索区域或整个桌面。游戏全屏时即游戏全屏范围。
- 此模式忽略图片锚点与像素偏移；旧流程保持原有行为。

### 兼容性提醒
含比例落点的新分享包请使用 v0.4.9 或更新的兼容版本执行。旧程序可能忽略新字段并点击原图片位置。新程序仍可导入原有格式版本 1 分享包。

### 验证范围
包含步骤选择、拖动手柄、专家参数显隐、比例坐标边界和分享包往返测试。发布流程执行 Windows 格式检查、Clippy、自动化测试及 release 构建。尚未完成 Windows 实机游戏中的点击、DPI 和全部界面布局验证。
