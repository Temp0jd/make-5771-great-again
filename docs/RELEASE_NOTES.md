## v0.7.4 · 性能收尾、键盘操作与新编排条件（未发布）

### 性能
- 撤销快照不再每帧序列化整份流程（改为 250 ms 节流；撤销/重做时强制检查），并按总字节数（4 MB）裁剪撤销栈。
- 开跑时只解码“被执行步骤真正引用”的模板：模板库很大但流程只用几张图时，启动明显更快。

### 可用性
- 手工绘制的控件（底部导航页签、步骤卡、模板网格单元）现在支持键盘：聚焦后按 Enter / 空格即可激活，配合已加宽的焦点环可直接键盘操作。
- 模板库的「引用 N 处」变成可点击：弹出「模板引用位置」，列出所有引用它的步骤（含子流程），点击「跳转」直接定位到该步骤。
- 深色模式新增「跟随系统深色」：随 Windows 应用主题自动切换，手动开关此时禁用。
- 启动清理：删除 30 天前的日期日志、只保留最近 20 个报表 CSV（失败现场快照仍保留最近 40 份）。

### 新增编排能力
- 步骤新增「从第几轮开始执行」：填 3 表示前两轮跳过该步骤，适合“先热机、后操作”的流程；步骤摘要会显示「第 N 轮起」。
- 新增「计划开始时间」：填 HH:MM 后点击「开始运行」会先等待到该时间（当天已过则等到明天），等待期间可随时停止或暂停。

### 维护
- CI 升级 `actions/checkout` 到 v5，消除 Node 20 弃用告警；Windows CI 依旧执行 fmt / clippy / 测试 / release 构建。

### 说明
- 未改变识别算法、流程数据语义与 `.m5771pack` 格式；旧分享包可直接导入。
- Windows 实机观感与真实游戏中的后台点击效果仍需你实机确认。

## v0.7.3 · 皮肤、后台点击与运行报表

### 新增：配色皮肤
- 设置页「界面与外观」新增皮肤选择：弥萨格金（默认）、深海青、杏白暖、暗夜红；每套皮肤都包含浅色与深色两版，切换立即生效并随流程保存。
- 皮肤只改变配色，不改动角色表情与装饰图；自动化测试会为**每套皮肤 × 浅/深色**校验正文 ≥7:1、次要/三级文字 ≥4.5:1、主按钮 ≥4.5:1、控件边界 ≥3:1。

### 后台点击与后台截图
- 截图改为三级回退：屏幕拷贝 → 窗口拷贝 → `PrintWindow(PW_RENDERFULLCONTENT)`；前一级只截到纯色（黑屏）时自动降级，运行开始会在日志里写明本次用的方式。
- 后台点击改为向**该坐标下最深的子窗口**投递 `WM_MOUSEMOVE` + `WM_LBUTTONDOWN` + `WM_LBUTTONUP`，并加入真实按压时长；很多游戏把画面渲染在子窗口里，之前只发给顶层窗口所以无效。
- 新增点击方式「后台点击＋临时前台注入」：为这一次点击临时把游戏切到前台并用真实输入注入，随后自动还原原来的前台窗口与鼠标位置——适用于直读输入、忽略窗口消息的游戏（如部分 Unity 游戏）。
- 新增开关「游戏不在前台时也继续识别与点击」（默认关闭）。默认行为不变：失去前台即自动暂停。开启后需保持窗口可见，被完全遮挡时可能只能截到黑屏。
- 说明：真正“游戏完全不显示也能点击”需要虚拟输入驱动（如 ViGEm 类内核驱动），本项目不引入驱动，因此以上为不装驱动的可行方案。

### 新增：运行报表
- 运行页新增「本次运行统计」：完成局数、平均/最短/最长每局耗时、平均识别相似度、失败最多的步骤 Top3、命中最多的模板 Top3。
- 支持「导出 CSV」到 `logs/report-时间.csv`；统计在每次开始运行时重置。

### 新增：配置备份与回滚
- 保存流程时自动保留上一版到 `profiles/backups/<流程名>/`（最多 5 版）。
- 「设置 → 流程信息」列出最近 5 个备份，可一键「恢复此版本」；恢复前会把当前版本再存一份。

### 性能与稳定性
- 日志改为缓冲批量写入（每 32 行或遇到警告立即 flush），运行结束时与应用退出前强制落盘。
- 流程与公共模板库改为“先写临时文件再原子替换”，断电或崩溃不会写坏配置。

### 内部实验模块（未接入界面）
- 新增 `src/economy.rs`：黑印（金币）数字模板读数、优先级购买计划、金币变化检测，全部为纯函数并有单元测试。
- 该模块**没有**任何界面入口，`MacroProfile.economy` 目前只会写入默认值；设计说明与接入步骤见 [ECONOMY_MODULE.md](ECONOMY_MODULE.md)。

### 说明
- 未改变识别算法、流程数据语义与 `.m5771pack` 格式；旧分享包仍可直接导入。
- Windows 实机观感、不同 DPI 与真实游戏中的后台点击效果仍需你实机确认。

## v0.7.2 · 控件可见性、失败恢复与界面优化

### 修复
- 开关类控件（「深色模式」「拟人化」「智能 ROI 越界恢复」「点击前二次确认」「到达条件后完成当前对局」「命中后点击触发目标」）在关闭时只有文字、没有边框，难以辨认；现改为始终绘制轨道、描边和「开启 / 关闭」状态文字。
- 未选中控件（下拉框、次级按钮、复选框）的底色与描边整体加深，控件的非文本对比度达到 3:1，浅色与深色主题下都能看清边界。

### 新增：截图与识别区合并框选
- 步骤模板行新增「截图＋识别区」：截取整帧后同时框两个框——蓝框=截图区（成为模板图），绿框=识别区（这一步的搜索范围）；两框都能拖动移动、拖右下角缩放，在空白处拖动会新建当前选中的框。
- 快捷操作：「识别区=全屏」（不做区域限制）、「识别区=截图区」、「重置」；应用后一次写入模板与搜索范围，识别区留空即全屏搜索。

### 界面
- 设置页改为分类导航（界面与外观 / 流程信息 / 目标窗口 / 识别与点击 / 失败与恢复 / 快捷键与保护 / 本地数据），不再是一条长滚动。
- 模板库新增名称搜索与「列表 / 网格」切换；网格视图在预览下方直接标记「引用 N 处 / 未引用」，并显示模板总数与引用统计。
- 底部导航选中项与开关加入过渡动画；键盘焦点环加宽到 2px，便于键盘操作时定位。
- 提示弹窗改为同时显示最近 3 条消息（最新在前），悬停暂停计时，仍可点击「关闭」或按 Esc。

### 新增：调试运行与步骤复用
- 运行页新增「调试运行」：可指定起始步骤（跳过前面的步骤），或开启「运行一步后自动暂停」，配合「继续运行」逐步验证某一步。
- 步骤「操作」菜单新增「复制到剪贴板」「在下方粘贴」：可把步骤（含分支、动作、视觉条件与优先级配置）复制到同一流程或其它流程，粘贴时自动分配新 ID；流程页会显示当前剪贴板内容。

### 新增：失败自动恢复与现场诊断
- 步骤超时后先按「超时后补充扫描」（默认 2 次）做快速补扫；仍失败则探测前后步骤（默认前后各 3 步）确定游戏当前进度：命中序号最靠后的可见步骤就从该步继续，不会盲目回退到前几步卡死。
- 无法定位当前进度时按设置执行「从头重新执行本流程」（默认）或「停止并提醒」；最多自动恢复次数默认 3 次，可在设置页调整。恢复过程只识别、不点击，并写日志。
- 最终失败时自动保存现场：`logs/frames/时间-步骤.png` 与同名 `.json`（步骤、模板、阈值、最佳相似度、是否歧义、画面尺寸），最多保留 40 份，并在日志中给出路径。

### 新增
- 识别范围编辑器新增「全屏」「铺满画面」「清除选择」快捷按钮：不想框选时可直接改为全屏搜索，或一键铺满当前画面。
- 运行页新增「暂停 / 继续」：暂停期间不识别、不点击，当前步骤超时顺延；与“失去前台自动暂停”相互独立，各自恢复。

### 性能
- 空闲时不再持续高频重绘：运行中 / 截图倒计时 / 模板测试时 120ms，其余情况 600ms；全局热键由工作线程直接唤醒界面，响应速度不依赖轮询间隔。
- 模板库缩略图按预览宽度（160px）上传 GPU，原图仍用于识别；模板库变化时清理不再使用的缩略图缓存。
- 日志内存最多保留 2000 条（文件日志完整保留），列表改为按固定行高虚拟化渲染，长消息悬停查看全文。

### 界面
- 日志页新增级别筛选（全部 / 信息 / 成功 / 警告，含条数）与关键字搜索。
- 浅色与深色主题的三级说明文字对比度提高到 4.5:1 以上。
- 界面用语去掉“旧版兼容”“继承旧版频率”“范围兼容”等开发者措辞，改为用户可读的表达。

### 说明
- 未改变任何设置项的含义与默认值；Windows 实机观感仍需确认。

## v0.7.0 · 主流程 / 子流程与优先级选择框架

### 新增
- 主流程与子流程库分开编辑；通过引用调用，同一子流程可复用，顺序执行后返回主流程。
- 物品 / Buff 选择：确认阶段标志后，在配置的候选区域内识别，按优先、允许随机、禁止规则决策。
- 数据不足时可显式开启未知候选随机降级；默认关闭，禁止和冲突候选不参与随机。
- 保存、撤销重做、模板维护与分享包均包含子流程。
- 新增 `modular-subflows-draft.m5771pack` 配置草稿及 [框架说明](SUBFLOW_FRAMEWORK.md)。

### 界面与安全
- 默认显示专家设置，暂时隐藏简洁/专家模式切换入口。
- 保留角色装饰，补齐新界面标签的内嵌中文字形。
- 选择前连续复核阶段与候选；点击前再次验证，并检查停止和前台状态。

### 使用边界
- 初版只支持单层子流程，不支持后台事件打断、递归调用、价格/余额 OCR 或自动购买循环。
- 未知候选可能是禁选、空位或售罄项；随机降级无法保证排除未识别的禁选项，请核对候选区域。
- 示例包缺少图片模板，需绑定阶段、物品及确认按钮截图，并调整候选区域后才能运行。
- 含新步骤的分享包需要 v0.7.0 或更新的兼容程序；旧程序不认识新步骤种类。
- Windows 游戏实机及不同 DPI 下的实际效果尚未验证。

## v0.4.9 · 流程交互修复与窗口比例落点

### 修复
- 步骤卡片点击即可选择；独立拖动手柄负责排序，不再覆盖卡片按钮和操作菜单。
- 简洁/专家模式切换独立成行，并标注各自显示的参数；增加模式显隐回归测试。
- 步骤文字自动换行、阶段标题换行，模板预览限制宽高，减少布局溢出。
- 保留原有角色装饰；补齐新标签使用的内嵌中文字形。

### 新增：识别成功后点击窗口比例位置
在点击落点设置中选择「点击窗口比例位置」，设置横向、纵向百分比。例如 25%、75% 表示目标游戏窗口客户区宽度的 25%、高度的 75%。

- 仍须图片识别成功，不会无条件点击。
- 支持普通识别步骤、分支触发点击、分支后续识别动作和视觉条件点击。
- 比例基于整个目标窗口客户区，而不是图片、搜索区域或整个桌面。游戏全屏时即游戏全屏范围。
- 此模式忽略图片锚点与像素偏移；旧流程保持原有行为。

### 兼容性提醒
含比例落点的新分享包请使用 v0.4.9 或更新的兼容版本执行。旧程序可能忽略新字段并点击原图片位置。新程序仍可导入原有格式版本 1 分享包。

### 验证范围
包含步骤选择、拖动手柄、专家参数显隐、比例坐标边界和分享包往返测试。发布流程执行 Windows 格式检查、Clippy、自动化测试及 release 构建。尚未完成 Windows 实机游戏中的点击、DPI 和全部界面布局验证。
